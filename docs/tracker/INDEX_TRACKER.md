Portal kolom → **"Kesehatan Cache Worker"**, badge `HIT 100%`/`HIT 87% · 2× 1102`, entri lama tanpa field baru tetap tampil. **Ditolak/ditinggalkan**: hard purge + burst (`revalidatePath` hanya set `revalidate=0`, tidak menghapus), `/api/admin/clear-cache` (sama-sama `revalidatePath`, butuh auth, tak mencakup preview), slug tak dikenal (`page.tsx:83` → `notFound()`), endpoint benchmark CPU (sintetis, butuh kalibrasi sendiri), ubah konfigurasi cache (di luar izin). **Juga diamati**: `TypeError: MemoryQueue.send (reading 'includes')` di tail = pre-existing dari antrean revalidasi yang mengecek header `x-nextjs-cache: REVALIDATED` yang absen, bukan akibat perubahan ini. **Pelajaran (dicatat di log)**: verifikasi pasca-deploy wajib memeriksa **apa yang benar-benar terukur**, bukan sekadar apakah kode berjalan tanpa error — v1.3.64 lolos semua gerbang tapi tetap cacat rancangan karena tidak ada satu pun test yang memeriksa apakah respons benar-benar `MISS`.
